# 设计记录

## 风格

整体为小红书打卡分享风格：轻暖、真实照片感、白色信息卡、强标题、柔和阴影。手机 H5 以 430px 宽作为主要预览尺寸，高度限制在 9:16 安全区内；活动首页在手机框内滚动，相机页仍保持单屏操作。

## 活动首页

活动首页按原型图承接海报制作后的打卡任务：

- 顶部：标题“小红书打卡”，右侧规则入口。
- Hero：浅绿色活动卡，左侧“晒小红书 集成长值”，右侧艺术成长树。
- 成长值：`GrowthTreeIcon` 表示当前阶段，`GrowthStageStrip` 展示 14 个阶段；第 1 / 7 / 14 阶为明显大节点。
- 进度卡：白色卡片，展示 `0/14`、`7/14`、`14/14` 等累计天数；7 天节点使用伴读徽章，14 天节点使用荣誉奖牌。
- 奖励卡：7 天伴读权益为蓝绿磨砂玻璃+打开书徽章；14 天荣誉奖牌为金属奖牌+珐琅叶片。
- 今日任务：步骤为“制作海报 > 发布小红书 > 上传截图”，不同状态显示待完成、待上传、审核中、审核通过、已完成。
- 弹窗：规则、截图示例、7 天奖励、14 天奖励均使用白底大圆角卡，内容居中聚焦。

## 图形资产风格

- 不使用大众 3D Q 版，也不做吉祥物化。
- 质感方向：轻金属、珐琅、半透明磨砂塑料、少量柔和颗粒。
- 颜色：暖象牙白、叶绿、蜂蜜黄、珊瑚橙、雾蓝，避免单一紫蓝或纯米色主题。
- 代码实现：正式 UI 使用 SVG 组件，确保可缩放、可跟随状态变化；生成式方向图保存在 `public/assets/reward-growth-icon-direction.png` 作为后续视觉参考。

- `figma-template-03.webp`：阅读字数主题，包含“阅读4234字”“24天”。

## 可复用样式

- 主按钮：黑底白字，`50px` 高，`999px` 圆角。
- 活动页主按钮：黑底白字，`62px` 高，`999px` 圆角，左侧 `44px` 黄色圆形 icon。
- 圆形切换按钮：`42px`，黑底白字，轻阴影。
- 箭头切换：左右 `42px` 圆形按钮，黑底白字，按下轻微缩放。
- 海报卡片：`736 / 944` 模板比例，`22px` 圆角，强投影。
- 活动页卡片：`24-26px` 大圆角，白色半透明底，`0 18px 42px rgba(70,46,17,0.1)` 柔和阴影。
- 活动页小相机：顶部 `38px` 黑底圆形；海报卡右下 `50px` 白底圆形。
- 拍照快门：`66px` 白色圆形，外圈描边感。
- 摄像头翻转：拍照页右侧 `42px` 圆形图标按钮。
- Favicon：精致 3D 简洁风格，圆角蓝色渐变底，上深下浅；白色相机机身，深蓝镜头，镜头内圈为黄色高光；发布格式为 WebP。
- 浏览器标题：使用“小红书打卡相机”，强化产品感，去掉 Demo 感。

## 动效参数

- 模板切换：`0.56s`，`back.out(1.15)`。
- 页面入场：`0.45s`，`power2.out`。
- 控件点击反馈：`scale(0.94)`，`140-160ms`。
- 顶部元素入场：子元素 `0.055s` stagger。
- 活动页滚动：仅 `.activity-screen` 内部滚动，外层手机框不滚动。
- 成长树主图：`treeBreath 3.8s ease-in-out infinite`，轻微上下浮动和缩放。
- 14 阶小树苗：`saplingBreath` / `saplingBreathMuted` 使用 `steps(4, end)` 帧动画，每阶按 `80ms` 错峰呼吸；未达成阶段更轻，当前阶段更明显。
- 进度条层级：轨道线 `z-index: 0/1`，节点徽章 `z-index: 3`，徽章使用白色托底阴影避免轨道线穿过图标。

## 设计注意

拍照页不再用代码复刻模板文字，直接叠加透明 WebP，确保模板和 Figma 保持一致。无摄像头权限时，用 `source-*.webp` 场景图作为 fallback。首页预览现在也使用“场景图 + 透明模板”叠合，更接近拍照结果。

布局需要优先适配移动浏览器工具栏：外层使用 `100svh` 和 9:16 上限，底部控制区保留至少约 `20px` 安全距离。
